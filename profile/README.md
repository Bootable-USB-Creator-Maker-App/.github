## 🚀 At a Glance
Bootable USB Creator for Windows is a no-fuss tool for writing an ISO you already own onto a USB drive that boots. Its typical use is to create a Windows 11 bootable USB from official installation media you downloaded yourself, ready for a clean install or a repair session. You provide the ISO, choose a drive, and the app writes the media — it does not host, bundle, or download any operating system for you.

## 📦 What You Get
| Feature | What it does for you |
|---------|----------------------|
| ISO writing | Writes the ISO you supply to a USB drive so it can boot a PC. |
| Windows media support | Builds a Windows 11 bootable USB or a Windows 10 bootable USB from official media you provide. |
| Drive preparation | Formats and readies the chosen USB drive automatically before writing. |
| Safe target selection | Lists removable drives by name and size so you write to the right one. |
| Free to use | Lets you create bootable USB drives with no cost or paid upgrade. |

## 🎯 Quick Start
1. Get your ISO ready, such as official Windows installation media you downloaded yourself.
2. Insert a USB drive with enough space, backing up anything on it that you want to keep.
3. In Bootable USB Creator, pick the ISO and select the USB drive to write to.
4. Start the process and let the tool prepare your bootable USB.
5. When it is finished, eject the drive and boot the target PC from it.

## ❓ FAQ
**Is Bootable USB Creator free?**
Yes, it is a free tool for creating bootable USB drives from an ISO you already have.

**Which versions of Windows are supported?**
It runs on Windows 10 and Windows 11 (64-bit) and can write ISO images to a USB drive on both.

**Is my data secure?**
The tool runs on your own computer and only uses the ISO and USB drive you choose. Because writing to a drive erases its current contents, back up the USB drive before you start.
